# Pig Speed Calculator на Android

В этой папке (`android`) лежит приложение в виде PWA: `index.html`, `manifest.webmanifest`, `sw.js` и иконки.
Chrome на Android ставит его на главный экран как обычное приложение (своё окно, иконка, работает без интернета).

## Способ 1. Установка с адреса в интернете (рекомендуется)

PWA устанавливается только с адреса `https://`, поэтому папку нужно один раз выложить на бесплатный хостинг.

1. Выложите всю папку `android` (все 5 файлов) на любой бесплатный статический хостинг, например:
   - Netlify Drop: откройте https://app.netlify.com/drop и перетащите папку `android`;
   - GitHub Pages или Cloudflare Pages: загрузите файлы в репозиторий и включите Pages.
   Получите адрес вида `https://что-то.netlify.app`.
2. На телефоне откройте этот адрес в Chrome.
3. Нажмите меню `⋮` (три точки) справа вверху → «Установить приложение» (или «Добавить на главный экран»).
4. Подтвердите. Значок «Pig Speed Calculator» появится на главном экране.
5. Откройте приложение один раз при включённом интернете, после этого оно работает и без сети.

Обновление: загрузите на хостинг новые файлы. При следующем открытии с интернетом телефон возьмёт новую версию.

## Способ 2. Без хостинга: просто файл

1. Скопируйте `index.html` на телефон (USB, мессенджер, облако).
2. Откройте его в Chrome через «Файлы» → `index.html` → «Открыть в Chrome».
3. Работает полностью, но значка на главном экране не будет (Chrome не устанавливает приложения из локальных файлов).

## Способ 3. Настоящий APK-файл

1. Выложите папку по способу 1, получите адрес.
2. Откройте https://www.pwabuilder.com, вставьте адрес, нажмите Start → Package for stores → Android.
3. Скачайте .apk. На телефоне: Настройки → разрешить установку из этого источника → откройте .apk → Установить.

## Важно

- Сохранённые участки и настройки хранятся в самом телефоне (в данных Chrome/приложения). Они не переходят с компьютера на телефон и обратно.
- Если удалить данные Chrome или приложения, сохранённые участки пропадут.
- Файлы в `android` собираются командой `node launcher/make-pwa.js` из `index.html`. После правок `index.html` запустите её снова и выложите новые файлы.
