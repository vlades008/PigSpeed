Pig Speed

Калькулятор скорости снаряда и учёт запусков.

Android

Скачать приложение (APK)
  1. Нажмите кнопку и дождитесь загрузки файла.
  2. Откройте скачанный файл PigSpeedCalc.apk.
  3. Если телефон спросит, разрешите установку из этого источника (браузера).
  4. Нажмите «Установить» и откройте «Pig Speed».

Приложение само загружает последнюю версию при запуске, обновлять его вручную не нужно.

iPhone

  1. Откройте эту страницу в Safari.
  2. Нажмите «Поделиться» (квадрат со стрелкой).
  3. Выберите «На экран Домой» и нажмите «Добавить».
Открыть Pig Speed

Для iPhone приложение работает с экрана «Домой» и обновляется само. Отдельного файла для iPhone нет (нужна учётная запись Apple Developer).
