Pig Speed

Калькулятор скорости снаряда и учёт запусков.

Вас пригласили в команду Pig Speed.
Почта для регистрации:

Зарегистрируйтесь именно с этой почтой, иначе приглашение не сработает.

Какой у вас телефон?

Android

Скачать приложение (APK)
  1. Нажмите кнопку и дождитесь загрузки файла.
  2. Откройте скачанный файл PigSpeedCalc.apk. Если телефон спросит, разрешите установку из этого источника (браузера).
  3. Нажмите «Установить» и откройте «Pig Speed».
  4. В приложении: Запуски → Войти → Создать аккаунт, почта . Придумайте пароль.
  5. Откройте письмо от Firebase, нажмите ссылку подтверждения (проверьте «Спам»), вернитесь в приложение и нажмите «Я подтвердил».
Или продолжить в браузере без установки

Приложение само загружает последнюю версию, обновлять его вручную не нужно.

iPhone

  1. Откройте эту страницу в Safari (в других браузерах нельзя добавить приложение на экран «Домой»).
  2. Нажмите кнопку ниже и создайте аккаунт с почтой . Подтвердите почту по ссылке из письма (проверьте «Спам»).
Создать аккаунт
  1. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран Домой» → «Добавить».
  2. Откройте Pig Speed с экрана «Домой» и один раз войдите с этой же почтой. Дальше приложение обновляется само.

Отдельного файла для iPhone нет: для него нужна учётная запись Apple Developer.
